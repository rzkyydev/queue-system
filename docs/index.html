From chat to queue in seconds.

Five steps. No dashboards to configure, no API keys to paste.

  1. 01

    Connect TikTok Live

    Enter the TikTok username and connect.

  2. 02

    Viewer requests a song

    Chat messages are watched live. A request only needs a song title after the command.

    @viewer99 !song Never Gonna Give You Up
  3. 03

    Request enters the queue

    The request appears automatically in Queue System.

  4. 04

    Moderator manages the queue

    Moderators can use commands such as:

    !skip !done !remove !fastsong
  5. 05

    Show it on stream

    Use the localhost OBS overlay as a Browser Source.

    http://127.0.0.1:3333/overlay

List Commands & How to Use.

Complete command reference for viewers and moderators.

All Commands

Commands for song requests and queue information.

!song

Request a Song

Add a song request to the regular queue.

Usage !song song name Example: !song Perfect
!fastsong

Fast Track Request

Submit a request with Fast Track priority.

Usage !fastsong song name Example: !fastsong Numb
!queue

View Queue

Check the current song request queue.

Usage !queue No additional text required.
!skip

Skip Current Song

Skip the currently playing song and move to the next request.

Usage !skip No additional text required.
!done

Complete Current Song

Mark the current song as completed and remove it from the queue.

Usage !done No additional text required.
!remove

Remove a Request

Remove a song from the queue by username or position.

Usage !remove username/position Example: !remove @viewer99
